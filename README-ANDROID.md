# Trans Salomão Android

Aplicativo Android offline baseado na planilha Trans Salomão Gestão de Fretes.

- SQLite local no aparelho (sem servidor obrigatório)
- Cadastro de motoristas e conjuntos
- Registro de viagens por tonelada ou por viagem
- KM, KM/L, diesel, comissão e resultados automáticos
- Administradores oficiais: Felipe, Murillo, Emanuel, Clovis e Gizele
- Painel da Gerência
- Relatórios por período e exportação em PDF
- Backup do banco de dados para um arquivo escolhido no Android

Pacote Android: `com.transsalomao.fretes`
