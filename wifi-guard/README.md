# WiFi Guard Enterprise

Android app para auditoria defensiva de Wi‑Fi.

Inclui scanner de redes, classificação Open/WEP/WPA/WPA2/WPA3/OWE/Enterprise, indicadores WPS/TKIP/PMF quando expostos pelo Android, score de segurança, alerta de SSID inconsistente, auditoria básica do gateway, análise offline de PCAP/EAPOL M1–M4 e laboratório seguro de conceitos de força bruta/WPS/WEP/deauth.

Não transmite deauth, não tenta PIN WPS, não quebra credenciais reais e não usa handshake para recuperar senha.
